# Glass UX component catalogue

Current release: **0.11.7** (2026-10-29). The installed package contains **391 API
pages** and **160 public export keys**. Use its `docs/api/README.md` for current
contracts. New entries since the preceding audit include SignaturePad, EditableAvatar,
RelationshipCanvas and LevelGauge, plus Stepper section navigation and read-only Segmented.
Librarian has no signature/profile-upload/schema-editor backend contract to wire to these;
no unrelated screens or fixture services are introduced merely to use components.

The detailed initial adoption inventory below is a **historical 0.9.10 snapshot**.
See [the current route audit](upgrade-audit-2026-10-29.md) for present compliance.

## Initial 0.9.10 adoption inventory

Review scope: every Markdown API component entry in the installed release, its public
entry, and the relevant integration/typed-input guides. There are **353 API pages**
across **95 documented component families** and **130 package export keys** (including
styles, assets, adapters and AI subentries). This inventory distinguishes a useful
current replacement from an unrelated capability; it does not propose new product areas.

The package includes all component API pages locally in `web/node_modules/glass-ux/docs/api/`.
Links below pin the source documentation to `v0.9.10`, rather than a moving live site.
